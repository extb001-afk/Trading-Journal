# tools/oneoff — 지난 판에서 한 번 돌린 1회 도구 (지금 돌릴 필요 없음)

이 폴더는 **특정 판의 데이터를 한 번 바로잡으려고 만든 도구**를 판(적용 날짜)별로 모아 둔 곳입니다.
지금 설치·업데이트·운영에 필요한 것은 없습니다 — 기록과 옛 안내 호환용으로만 남겨 둡니다.
지금 쓰는 운영 도구(재구축 `tools/rebuild2.py` · 복구 `tools/ledger_restore.py` · 업데이트 뒤 1회 점검 `tools/token_recheck.py` · `tools/negabs.py` ·
`tools/bithumb_filltime.py` 등)는 그대로 `tools/` 에 있고, 언제 쓰는지는 [docs/OPERATIONS.md](../../docs/OPERATIONS.md) '운영 도구'에 있습니다.
