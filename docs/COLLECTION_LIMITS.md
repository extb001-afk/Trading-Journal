# 수집 한계 — API 로 되는 것과 안 되는 것

tj-bot 은 거래소·체인이 API 로 주는 기록만 모읍니다. API 가 주지 않는 옛 기록을 우회해서 가져오지 않습니다(거래소 아카이브 신청·CSV 가져오기 없음). 못 받는 부분은 아래에 적어 두었으니, 필요한 경우 '이용자가 할 일'로 직접 정해 주세요.

- 봇의 기본 수집 기간은 최근 5개월(config backfill_months)이고, backfill_since 로 앞당길 수 있어요. 아래 '봇이 받는 범위'는 그 수집 기간 안에서의 이야기예요.
- 거래소 API 키는 **조회(읽기) 권한만** 켠 키를 쓰세요. 바이낸스·바이비트·OKX 는 저장할 때 키 권한을 자동으로 확인해 거래·출금·이체 권한이 켜져 있으면 저장하지 않고, 권한을 API 로 확인할 수 없는 거래소(업비트·빗썸·쿠코인·게이트)는 '조회 권한만 켰음' 확인이 있어야 저장합니다.
- 같은 내용이 화면 **설정 › 수집 한계 › 거래소·체인별 한계 정리**에도 있습니다(정리 기준일 2026-10-08).

## 이용자가 할 수 있는 일

- **원가 입력** — 원가 미확인 목록에서 그 코인의 '원가 적용'에 개당 원가(USD)를 넣어요(거래소 웹·앱의 옛 체결 내역을 보고)
- **당시 시세로 추정** — 원가 미확인 목록에서 '당시 시세로 추정'을 눌러 들어온 날 시세를 원가로 써요
- **손익 0 처리** — 원가 미확인 매도 행에서 '손익 0으로 처리'(매수가 = 매도가로 봐요, 되돌리기 가능)
- **오프체인 이체 가정** — 설정에서 그 거래소의 '오프체인 이체를 내 계정 간 이동으로 가정'을 켜요(내 다른 계정끼리 옮긴 것일 때만)
- **출발지 등록** — 그 코인이 온 지갑·거래소를 등록하면 원가를 이어받아요
- **수집 시작일 앞당기기** — config.json 의 backfill_since(YYYY-MM-DD)를 앞당기면 API 가 주는 범위 안에서 옛 구간을 더 받아요
